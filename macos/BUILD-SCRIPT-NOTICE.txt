The copy is not edited in place. macos/build.sh applies the patches in
macos/patches/ to a working copy at build time. The changes are:
  01-download-sha256-archive.patch  download() verifies every file against
                                    macos/sources.sha256 and keeps a copy for the
                                    source archive; meson is installed at a pinned version.
  02-pin-x264.patch                 x264 from commit 0480cb05fa188d37ae87e8f4fd8f1aea3711f7ee
                                    instead of the moving master branch.
  03-extra-version.patch            the version suffix names this build
                                    ("racedash-ffmpeg") instead of the upstream build server.
